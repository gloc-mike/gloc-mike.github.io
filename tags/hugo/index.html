Beautifulhugo Theme Extras - Shortcodes (Split)

Another extra beautifulhugo theme shortcode is called split. This shortcode splits the page into two columns. The example shown in the doco in the beautifulhugo repo (at the time of writing) was a little confusing because the closing endcolumns tag was incorrect (missing an s). Got there in the end. 😅 It should look like this: 1 2 3 4 5 {{< columns >}} First column on the right side of the page {{< column >}} Second column on the left side of the page {{< endcolumns >}} Yes, the first tag is columns whereas the intermediate tag is column. Beautifulhugo Theme Extras - Shortcodes (Details)

An extra beautifulhugo theme shortcode is called details (checking the code itself shows that it is based on the HTML <details> tag). This shortcode hides some content until the text set on the detail is clicked. An example follows: Click here to expand to show hidden content! This is the content you’d like to hide. 🧘 The actual code used in this post for the previous example looks like this: 1 2 3 {{< details "Click here to expand to show the content!" >}} This is the content you'd like to hide. 🧘 {{< /details >}} I had trouble adding spacing to the content in the details shortcode above so I resorted to adding HTML <br> tags but that didn’t work either.
